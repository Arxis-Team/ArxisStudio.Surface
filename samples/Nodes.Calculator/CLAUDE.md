# CLAUDE.md

Пример `Nodes.Calculator` — калькулятор в духе Blueprint Unreal Engine на редакторе узлов. Файл грузится,
когда работают под этим каталогом. Про библиотеку сказано в `CLAUDE.md` в корне репозитория, про соседние
образцы — в `samples/Nodes.Demo/CLAUDE.md` и `samples/Nodes.StateMachine/CLAUDE.md`.

Как и соседи, пример проверяет библиотеку на потребителе: он написан только на публичном API
`ArxisStudio.Surface.Nodes`. Ради него библиотека получила одно событие — `ConnectDropped` (ADR 0018):
без сообщения о проводе, отпущенном в пустоту, палитру «из пина» не построить.

## Что на экране

- Сверху: «▶ Играть» (F5), «Импульсы», «Пример» (вернуть исходный граф), «Показать всё», отмена и повтор.
- Слева — «Мой Blueprint»: переменные графа и их значения по умолчанию.
- Посередине — холст. Строки «Вывести строку» появляются поверх холста сверху слева, голубым, как Print
  String на экране игры.
- Снизу — «Журнал вывода» (Output Log).

## Модель (`Graph/`)

- **Определение узла** — `NodeDefinition`, строка каталога `NodeCatalog`:
  - название, раздел меню («Математика|Число»), вид (`NodeLook`), знак компактного узла;
  - ключевые слова поиска, порты с литералами по умолчанию;
  - счёт чистого узла (`Compute`) и добавляемый пин (`ExtraPin`).
- **Узел** — `CalcNode`: определение, место, наблюдаемые коллекции портов, предупреждение. Узел
  переменной держит `CalcVariable` и следует за её переименованием. Излом — `RerouteNode`.
- **Порт** — `CalcPort`. Его тип (`PinType`) даёт цвет штырька и провода — оттенки пинов UE5, поднятые
  под тёмный холст. Выполнение — роль пина (ADR 0017), без своей кисти.
  - Неподключённый вход данных хранит литерал текстом (`Text`), у логического — флажок (`Flag`) поверх
    того же текста.
  - Выход держит `Display` — значение живого счёта.
- **Провод** — `CalcLink`, класс с уведомлением. Тип излома выясняется по подключённым проводам
  (`CalcDocument.Retype`), и уже лежащий провод перекрашивается.
- **Виды узлов** — как полосы Blueprint:
  - событие — красный;
  - вызов функции — синий, «ƒ»;
  - чистая функция — зелёный, «ƒ»;
  - управление потоком — серый;
  - компактный узел математики без заголовка, со знаком посередине;
  - узел преобразования «•»;
  - «таблетка» чтения переменной.

  У компактных узлов и узлов переменных `Header` и `Accent` — `null`, и библиотека не рисует области
  заголовка.

Каталог (`NodeCatalog.All` и `ForVariables`):

| Раздел | Узлы |
| --- | --- |
| События | «Начало игры» — одно на граф |
| Поток выполнения | «Ветвление», «Последовательность» (+ пин «Затем N»), «Цикл For» |
| Математика › Число | «+» и «×» (+ пин); «−», «÷», «%»; «Степень», «Квадратный корень», «Модуль», «Мин», «Макс», «Округлить» |
| Математика › Сравнение | «>», «<», «≥», «≤», «==» |
| Математика › Логика | «И», «ИЛИ» (+ пин), «НЕ», «Выбрать» |
| Строки | «Соединить» (+ пин) |
| Преобразования | целое в число, число в целое, число, целое и логическое в строку |
| Утилиты | «Вывести строку»: «Строка», «На экран», «В журнал», «Длительность» |
| Переменные | «Получить X», «Задать X» — для каждой переменной |

Деление на ноль и корень из отрицательного дают ноль и предупреждение над телом узла — как «Warning!»
у Blueprint.

## Правила соединения (`CalcDocument.Check`)

Библиотека правил не знает (ADR 0016). Окно спрашивает их в `ConnectValidating`:

- в свой узел нельзя;
- выполнение соединяется только с выполнением;
- одинаковые типы соединяются напрямую, излом без провода — с любым типом;
- разные типы соединяются, только если есть узел преобразования. Окно ставит его само посередине между
  пинами — как Blueprint при соединении целого с числом;
- провод данных не должен замкнуть кольцо. Кольцо выполнения можно: это цикл, и «Играть» остановит его на
  1000-м шаге;
- занятый вход данных и занятый выход выполнения не отказывают. Новый провод заменяет прежний вместе с
  повисшими изломами, одной записью истории;
- перецепляемый конец узла преобразования не ставит: провод остаётся одним проводом.

## Счёт (`Graph/Evaluator.cs`)

- **Живой счёт** (`Preview`) после любой правки — одним проходом на кадр (`QueueRefresh`). Он спрашивает
  каждый выход данных с переменными по умолчанию и пишет `Display`. Значения видно ещё до запуска.
- **Чистый узел** считается, когда его спросит выполняемый узел, — каждый раз заново, как в Blueprint.
- **«Играть»** (`Run`) идёт по проводам выполнения от каждого «Начала игры»:
  - «Последовательность» проходит все «Затем» по порядку;
  - «Цикл For» — тело для каждого индекса, потом «Завершено»;
  - «Задать» пишет переменную прогона.

  Прогон записывается шагами (`TraceEvent`). Провод выполнения — новый миг; провода данных, прочитанные
  узлом, — тот же миг, что и узел; излом своего мига не занимает. Окно проигрывает запись шагом 160 мс:
  - провод вспыхивает импульсом своего цвета — выполнение цветом роли из темы (ADR 0014);
  - «Вывести строку» пишет на экран на свою длительность и в журнал строкой
    `LogBlueprintUserMessages: [Калькулятор] …`.

  После 1000 узлов выполнения прогон останавливается: ошибка «Бесконечный цикл» идёт в журнал, а
  предупреждение — на узел.

## Меню действий (`Actions/`)

`ActionMenu` — поставщик действий и их показ (`ISurfaceContextPresenter`) одним объектом.

- **Правая кнопка по пустому холсту** открывает `ActionPalette` — «Все действия для этого Blueprint»:
  - поле поиска, разделы деревом;
  - поиск по словам: каждое слово запроса ищется в названии, ключевых словах и разделе. «+» находит
    «Сложить», «строк выв» — «Вывести строку»;
  - стрелки двигают выбор, Enter выполняет, Esc закрывает, щелчок выполняет сразу.
- **Провод из пина, отпущенный в пустоту** (`ConnectDropped`), открывает ту же палитру с флажком «С
  учётом контекста». В ней только узлы, у которых есть пин, способный принять провод напрямую или через
  преобразование. Новый узел встаёт в точку броска: от входа — слева от неё. Он подключается первым
  таким пином в порядке пинов — так, от числа, «Вывести строку» берёт «Строку» через преобразование, а
  не «Длительность». Узел, провод и преобразование — одна запись истории.
- **Правая кнопка по узлу** — обычное контекстное меню библиотеки: «Добавить пин», «Убрать последний
  пин», «Разорвать все связи», «Удалить».

## Литералы и отмена

- Поле литерала лежит в `Panel.literal`. Стиль окна прячет панель у подключённого порта
  (`surface|Port:connected Panel.literal`). Прячется панель, а не само поле: у поля своя видимость
  привязкой по типу, и значение стиля локальную привязку не перекрыло бы.
- Правка поля — одна запись истории от фокуса до ухода с поля. Enter принимает, Esc возвращает прежнее.
  Флажок ложится записью на щелчке.
- Пустое имя переменной не принимается.
- Delete в поле правит текст, а не удаляет узел: поле обрабатывает клавишу раньше редактора.

## Раскладка примера

Граф — гипотенуза по катетам A = 3 и B = 4, ветвление по сравнению с 4,5 и цикл квадратов:

- сверху — выполнение: «Начало игры» → «Последовательность» → «Вывести строку» → «Ветвление»;
- под ним — чистые узлы гипотенузы;
- ниже — цикл: индекс проходит в «×» через преобразование целого в число;
- «Затем 1» спускается к циклу по коридору между «×» и «+».

Прогон пишет:

```
Гипотенуза: 5
Больше 4,5
Квадрат: 1
Квадрат: 4
Квадрат: 9
Готово
```

Узел вне окна живёт без контейнера, и охват считает его по оценке размера, а пузыри значений
расширяют узлы уже после счёта. Поэтому окно вписывает граф после первого живого счёта и довписывает,
пока охват не устоится (`Fit`, до трёх проходов). Миникарты у примера нет: у Blueprint её нет, а угол
холста она закрывала узлом.

## Проверка вживую

- Запускать собранный exe.
- MCP DevTools: `AVA_DEVTOOLS_MCP=1`, `AVA_DEVTOOLS_MCP_PORT=5178` (5171–5177 заняты студией, витринами,
  демо и машиной состояний), `AVA_DEVTOOLS_MCP_INPUT=1`.
- Снимок окна — `PrintWindow`. Палитра — отдельное окно попапа: снимок экрана или `list_popups`.
- Кириллицу в `type_text` передают `\u`-экранами.
- Закрывать — по номеру процесса.

Что проверено так:

- Живой счёт: A = 6 даёт «Гипотенуза: 7,2111», две отмены возвращают 3.
- Палитра по правой кнопке: «+» и Enter ставят «Сложить».
- Провод из выхода «+» в пустоту открывает контекстную палитру. «Вывести строку» встаёт подключённой к
  «Строке» через преобразование.
- «Добавить пин» мышью, затем Ctrl + Z.
- Флажок и его отмена.
- Delete и Esc в поле литерала.
- Излом двойным щелчком по проводу выполнения.
- Меню узла.
- «Играть»: импульсы по проводам выполнения и данных, шесть строк на экране и в журнале.
